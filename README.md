Portfolio personnel de **Zakaria Oulharir**, étudiant en deuxième année de Développement Digital – option Web Full Stack à l’ISTA Azilal (OFPPT), Maroc.

- Présentation et parcours de formation.
- Compétences techniques et technologies en cours d’apprentissage.
- Projet pédagogique **Madrassati** avec une description transparente de son état d’avancement.
- Coordonnées et lien vers GitHub.

## Technologies présentées

HTML5, CSS3, JavaScript, Node.js, Express, MySQL, PHP (notions), Git et GitHub. React et Laravel sont indiqués comme technologies en cours d’apprentissage.

## Modifier le contenu

Le contenu du site est centralisé dans `config.js`. Les textes, compétences, projets et coordonnées peuvent être modifiés dans cet objet.

## Lancer le portfolio en local

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/zyrex1a/Portfolio.git
   ```
2. Ouvrir le dossier du projet.
3. Ouvrir `index.html` dans un navigateur.

Le site est construit en HTML, CSS et JavaScript natifs ; aucune installation de dépendances n’est nécessaire.
